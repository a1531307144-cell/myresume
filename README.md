# 我的简历（MyResume）

> 简单好用的桌面简历编辑器 —— 空白起步、板块自由增删排序、所见即所得、导出可选中文字的高质量 PDF。

![平台](https://img.shields.io/badge/平台-Windows-blue) ![协议](https://img.shields.io/badge/License-MIT-green)

## ✨ 功能

- **空白起步**：打开就是一张白纸，没有任何预填内容，隐私干净
- **板块自由**：基本信息 / 教育背景 / 实习·研究·项目·校园经历 / 技能证书 / 荣誉奖项 / 自我评价 / 自定义文本——随意增删、改名、排序
- **两套内置模板**：法学正式风（宋体·黑白稳重·照片右上角）+ 通用简约风（现代无衬线），一键切换、数据无损
- **所见即所得**：右侧 A4 纸张实时预览，预览换行位置与导出 PDF 完全一致
- **高质量 PDF**：矢量文字导出——可选中、可搜索、体积小、分页整齐不切字
- **数据在你手里**：简历保存为本地文件，自动保存防丢，照片内嵌单文件可移植
- **自动更新**：新版本后台静默下载，一键安装

## 📥 下载安装

> 首个正式版本尚未发布（当前处于开发阶段）。发布后请到 [Releases](../../releases) 页面下载最新版安装包。

**首次安装提示**：本软件为个人开源软件，未购买商业代码签名证书，Windows 可能弹出「已保护你的电脑」蓝色提示——点击「更多信息」→「仍要运行」即可，属正常现象。

## 🛠️ 从源码构建

```bash
npm install        # 安装依赖
npm run dev        # 开发模式运行
npm run dist       # 构建 Windows 安装包
```
