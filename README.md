# 我的简历（MyResume）

> 简单好用的桌面简历编辑器 —— 空白起步、板块自由增删排序、所见即所得、导出可选中文字的高质量 PDF。

![平台](https://img.shields.io/badge/平台-Windows-blue) ![协议](https://img.shields.io/badge/License-MIT-green)

## ✨ 功能

- **读取已有简历（v0.2.0 新增）**：把 Word（.docx）/ 文字版 PDF / TXT 拖进窗口或点击导入，自动解析成板块；可选接入你自己的 AI（OpenAI 兼容接口）获得更准的解析，全程可视化进度
- **空白起步**：打开就是一张白纸，没有任何预填内容，隐私干净
- **板块自由**：基本信息 / 教育背景 / 实习·研究·项目·校园经历 / 技能证书 / 荣誉奖项 / 自我评价 / 自定义文本——随意增删、改名、排序
- **两套内置模板**：法学正式风（宋体·黑白稳重·照片右上角）+ 通用简约风（现代无衬线），一键切换、数据无损
- **排版个性化**：字体（宋体/雅黑/楷体/仿宋/黑体）、字号、行距随你调，设置随文件保存
- **所见即所得**：右侧 A4 纸张实时预览，预览换行位置与导出 PDF 完全一致
- **高质量 PDF**：矢量文字导出——可选中、可搜索、体积小、分页整齐不切字
- **多窗口**：新建简历开新窗口，多份简历互不干扰
- **数据在你手里**：简历保存为本地文件，自动保存防丢，照片内嵌单文件可移植
- **自动更新**：启动时检查新版本，由你决定是否下载安装（不擅自下载）

## 📥 下载安装

1. 打开 [**Releases 发布页**](../../releases/latest)
2. 下载 **`MyResume-Setup-x.x.x.exe`**
3. 双击安装（可自选安装目录，自动创建桌面快捷方式）

### ❓ 安装时出现「Windows 已保护你的电脑」？

本软件为个人开源软件，未购买商业代码签名证书（年费数千元），Windows 会显示蓝色警告，**属正常现象**，按下面步骤放行即可：

1. 在 SmartScreen 蓝色提示框上点击 **「更多信息」**
2. 出现 **「仍要运行」** 按钮，点击即可正常安装

> 如需校验安装包完整性，可下载 Release 中的 `SHA256SUMS.txt`，与下载的 exe 哈希比对（PowerShell：`Get-FileHash 文件名 -Algorithm SHA256`）。

## 🔄 更新

软件启动时会自动检查新版本，发现新版后后台静默下载，点击「重启安装」即可完成升级。若自动更新缓慢（GitHub 直连），也可直接到 [Releases](../../releases/latest) 下载新版安装包覆盖安装——**你的简历文件保存在你自己的位置，升级/卸载都不受影响**。

## 🛠️ 从源码构建

```bash
npm install        # 安装依赖
npm run dev        # 开发模式运行
npm run dist       # 构建 Windows 安装包
```
