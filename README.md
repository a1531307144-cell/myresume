# 我的简历（MyResume）

> 简单好用的桌面简历编辑器 —— 空白起步、板块自由增删排序、所见即所得、导出可选中文字的高质量 PDF。

![平台](https://img.shields.io/badge/平台-Windows-blue) ![协议](https://img.shields.io/badge/License-MIT-green)

## ✨ 功能

- **AI 参与编写与润色（v0.3.0 新增）**：每个板块点 ✨AI 就能改写或从零生成——左边原文、右边 AI 新版并排对照，你点「采纳替换」才写进简历。AI 只改措辞，时间、单位、职务等事实信息一律照抄，也禁止编造数字与经历
- **AI 全文诊断（v0.3.0 新增）**：让 AI 通读整份简历，列出具体问题（哪段太空泛、哪里缺数字、和求职意向是否对得上），每条都能一键跳到对应板块去改
- **单窗口标签页（v0.3.0 新增）**：一个窗口里用标签同时管好几份简历，「首页」是常驻第一个标签——随时切回去，再点回来不用重开
- **读取已有简历**：把 Word（.docx）/ 文字版 PDF / TXT 拖进窗口或点击导入，自动解析成板块；可选接入你自己的 AI（OpenAI 兼容接口）获得更准的解析，全程可视化进度
- **空白起步**：打开就是一张白纸，没有任何预填内容，隐私干净
- **板块自由**：基本信息 / 教育背景 / 实习·研究·项目·校园经历 / 技能证书 / 荣誉奖项 / 自我评价 / 自定义文本——随意增删、改名、排序
- **六套内置模板（v0.4.0 扩充）**：法学正式风（宋体·黑白稳重·照片右上角）、通用简约风（现代无衬线）、双栏侧边栏（深色侧栏·技能证书独立成栏）、时间轴（竖点线串联板块·中英双语标题）、表格线框（细线分区·信息密度最高）、顶部色带（顶部色带·大留白单栏）——一键切换、数据无损
- **排版个性化**：字体（宋体/雅黑/楷体/仿宋/黑体）、字号、行距随你调，设置随文件保存
- **所见即所得**：右侧 A4 纸张实时预览，预览换行位置与导出 PDF 完全一致
- **高质量 PDF**：矢量文字导出——可选中、可搜索、体积小、分页整齐不切字
- **数据在你手里**：简历保存为本地文件，自动保存防丢；没来得及保存的内容会留成草稿，下次启动在左下角提示你恢复
- **自动更新**：启动时检查新版本，**只提示、不擅自下载**——你点了「下载安装」才会下载

## 📥 下载安装

1. 打开 [**Releases 发布页**](../../releases/latest)
2. 下载 **`MyResume-Setup-x.x.x.exe`**
3. 双击安装（可自选安装目录，自动创建桌面快捷方式）

### ❓ 安装时出现「Windows 已保护你的电脑」？

本软件为个人开源软件，未购买商业代码签名证书（年费数千元），Windows 会显示蓝色警告，**属正常现象**，按下面步骤放行即可：

1. 在 SmartScreen 蓝色提示框上点击 **「更多信息」**
2. 出现 **「仍要运行」** 按钮，点击即可正常安装

> 如需校验安装包完整性，可下载 Release 中的 `SHA256SUMS.txt`，与下载的 exe 哈希比对（PowerShell：`Get-FileHash 文件名 -Algorithm SHA256`）。

## 🔄 更新

软件启动时会自动检查新版本，**发现新版只提示、不会擅自下载**；你点了「下载安装」才会开始下载，下载完再决定何时重启安装。若自动更新缓慢（GitHub 直连），也可直接到 [Releases](../../releases/latest) 下载新版安装包覆盖安装——**你的简历文件保存在你自己的位置，升级/卸载都不受影响**。

## 🛠️ 从源码构建

```bash
npm install        # 安装依赖
npm run dev        # 开发模式运行
npm run dist       # 构建 Windows 安装包
```
